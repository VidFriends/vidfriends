# VID-277 — Fix env var prefix, ownership check, eviction query

**Status:** `done`
**Date:** 2026-06-17

## Fixes Applied

### 1. Fix env var prefix — `internal/config/config.go`
Added 3 env vars with correct `VIDFRIENDS_` prefix (renamed from the incorrect `VIDFLOW_` prefix that was in the spec):
- `VIDFRIENDS_EVICTION_STRATEGY` (default: "age")
- `VIDFRIENDS_EVICTION_AGE_DAYS` (default: 90)
- `VIDFRIENDS_MAX_STORAGE_BYTES` (default: 0 = unlimited)

### 2. Missing ownership check on PATCH /api/videos/{id}/keep
Added `VideoHandler.Keep()` handler at `internal/handler/video.go`:
- Route: `PATCH /api/videos/{id}/keep` (auth required)
- Verifies `claims.UserID` matches the video's `user_id` before toggling `keep_forever`
- Returns 403 if the user does not own the video
- Accepts `{"keep_forever": true/false}` in request body

### 3. RunEviction not updated for keep_forever — `internal/handler/admin.go`
- Added `AND (keep_forever IS NULL OR keep_forever = false)` to both SELECT and UPDATE queries
- Replaced hardcoded `interval '90 days'` with config-driven `$1 * interval '1 day'` using `VIDFRIENDS_EVICTION_AGE_DAYS`
- Removed `'processing'` from evictable statuses (videos still being downloaded should not be evicted)

### 4. Migration — `migrations/000017_add_keep_forever`
Added `keep_forever BOOLEAN NOT NULL DEFAULT false` column to videos table with index.
